# Simple Calculator

Java Internship — Project 1

## Description
A desktop calculator application developed using Java Swing and Apache NetBeans IDE.

## Features
- Addition, subtraction, multiplication, and division
- Operator precedence
- Decimal number calculations
- Clear (C) and All Clear (AC)
- Division-by-zero error handling
- User-friendly graphical interface

## Technologies
- Java
- Java Swing
- Apache NetBeans IDE

## How to Run
1. Open the project in Apache NetBeans.
2. Set `simplecalculator.SimpleCalculator` as the main class.
3. Run the project using F6.
